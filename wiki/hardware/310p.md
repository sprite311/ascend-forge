# Ascend 310P

## 概览
昇腾 **310P 推理卡**，聚焦数据中心 / 边缘推理场景。典型产品：
- **Atlas 300I Pro**（PCIe，单卡）
- **Atlas 300I Duo**（双芯片卡）
- **Atlas 500 Pro 智能小站**（边缘推理服务器）

## 规格

| 项           | 值                         | 核实命令                          |
|--------------|----------------------------|-----------------------------------|
| 显存         | 8GB / 16GB（SKU 差异）     | `npu-smi info -t memory -i 0`     |
| FP16 算力    | 公开资料 ~140 TFLOPS       | —                                 |
| INT8 算力    | 公开资料 ~280 TOPS         | —                                 |
| 功耗         | ~72W (300I Pro) / ~150W (Duo) | —                              |
| 接口         | PCIe Gen4 x16              | —                                 |

> ⚠️ 具体数字未经本环境 / 官方白皮书核实；按低置信度使用。

## 使用注意
- **不支持训练**——显存 / 算力设计用途为推理
- 大模型在 310P 上必走**激进量化**（W4A16 或更低）或**模型切分**
- 推理路径：**ATC 离线（OM）** / **ONNX Runtime (CANN EP)** / **MindIE**
