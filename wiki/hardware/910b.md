# Ascend 910B

## 概览
华为昇腾 **910B 系列**，训推两用 AI 加速芯片。具体 SKU 分 **B1 / B2 / B3 / B4**，主要差异在显存和 IO。
典型产品：**Atlas 800T A2 训练服务器**、**Atlas 900 A2 PoD 集群**。

## 规格

> ⚠️ 具体数字按 SKU 差异较大；以下为**公开资料口径**，用户请用 `npu-smi info -t board -i 0` 核实。

| 项           | 值 (典型 B3/B4)            | 核实命令 |
|--------------|----------------------------|----------|
| 制程         | 7nm+ (公开资料)            | —        |
| AICore 数    | 见 `npu-smi info -t board` | `npu-smi info -t board -i 0` |
| HBM          | 32GB 或 64GB（SKU 差异）   | `npu-smi info -t memory -i 0` |
| HBM 带宽     | ~1.6 TB/s（公开资料）      | —        |
| FP16/BF16 算力 | ~320 TFLOPS（公开资料）  | —        |
| INT8 算力    | ~640 TOPS（公开资料）      | —        |
| 互联         | HCCS（卡间）/ RoCE（机间） | `npu-smi info -t topo`       |

> **数字来源于公开市场资料；未经本环境 / 官方白皮书核实前按低置信度使用**（见
> [`pitfall-wiki-seed-page-tbd-blind-answer`](../../memory/pitfalls/wiki-seed-page-tbd-blind-answer.md)）。

## 使用注意
- 与**无 B 的 910**某些驱动不兼容——型号确认用 `cat /usr/local/Ascend/driver/version.info`
- B1 / B2 显存 32GB，B3 / B4 显存 64GB，选卡前确认 SKU
- 多卡拓扑：单机 8 卡走 HCCS（带宽高）；跨机走 RoCE（需配 ranktable.json）
