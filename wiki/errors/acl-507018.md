# ACL stream synchronize failed · 507018

## 症状
推理调用（HuggingFace `model.generate` / vLLM / MindIE OpenAI 接口）偶发或必现 ACL 流同步失败，
栈底多半来自 `torch_npu/csrc/` 的 stream sync，伴随一句 `error code:507018`。

## 报错示例

```
RuntimeError: ACL stream synchronize failed, error code:507018
```

## 根因
`507018` 与推理期的**随机采样（sampling）实现**相关。昇腾 NPU 上的随机采样 kernel 与 CUDA 有实现差异，
在某些 top-p / top-k / temperature 组合下会触发 stream 同步异常。属于 CANN 对齐 gap，部分版本已修复。

## 修复（按优先级）

### 方案 A：关采样（最快，推荐先试）
```bash
# OpenAI-兼容接口
curl http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "your-model",
    "messages": [{"role":"user","content":"hi"}],
    "do_sample": false
  }'
```

```python
# 代码
outputs = model.generate(input_ids, do_sample=False, max_new_tokens=512)
```

### 方案 B：必须采样时的降级
- 降低 `temperature`（≤ 0.1）
- 固定 `random_seed`
- 升级 CANN 到最新版本（新版本部分修复）

## 验证
```bash
# 回归 20 次推理请求无 507018 即视为修复
for i in $(seq 1 20); do
  curl -s http://localhost:8000/v1/chat/completions \
    -H 'Content-Type: application/json' \
    -d '{"model":"m","messages":[{"role":"user","content":"hi"}],"do_sample":false}' \
    | jq -r '.choices[0].message.content' | head -c 20
  echo
done
```
