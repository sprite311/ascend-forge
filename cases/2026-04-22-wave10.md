# Wave 10 · skill runnable 化

## 触发

Wave 9 close 时识别出最大缺口：**12 个 skill 只有 1 个有 `run.sh`（其余仅 SOP 文档）**。
skill 没有 runnable entry 等于 **"5 天 → 0.5 天"** 链条最后一环没接通——一线队员读 SOP 还是要手敲命令、翻坑本。

Wave 10 目标：把**访问频率最高的 3 个 skill** 从"文档 SOP"升到"`./run.sh <mode>` 一键式"。

## 选哪 3 个？

按 Wave 9 沉淀的 pitfalls 和 playbook 的高频度触发点：

| skill | 对应 pitfall / playbook 步骤 | 为什么优先 |
|---|---|---|
| `model-adaptation` | playbook Step 3-4（eager load + 精度对齐） | HF→NPU 迁移的起点，所有队员都要过 |
| `vllm-ascend-serving` | `pitfall-block-size-alignment` + `pitfall-vllm-kv-cache-alloc-failed` | 参数一个错整个服务起不来 |
| `precision-alignment` | `pitfall-rope-half-convention-mismatch`（silent bug）| 首日必跑，不跑就是 5-day 返工 |

## 做了什么

### skills/model-adaptation/run.sh（124 行）

3 个模式：

- `env` — 驱动 / firmware / CANN / torch / torch_npu 自检，dry-run 友好（无 NPU 也能跑）
- `template-load <OUT.py>` — 生成 `AutoModelForCausalLM.from_pretrained(..., attn_implementation="eager")` 模板，自带 dtype 健康检查（防 `pitfall-dtype-mixing-bf16-fp16`）
- `template-diff <OUT.py>` — 生成 GPU↔NPU 逐层 diff 模板，带发散层诊断提示（rope/attn/norm 自动分类）

模板输出路径以 **存在则拒绝覆盖** 保护用户现有文件。

### skills/vllm-ascend-serving/run.sh（153 行）

3 个模式：

- `check` — 参数校验，**对 `--block-size != 64 && != 128` 直接 exit 1 + 指向 pitfall**
- `estimate` — 粗估单卡显存占用：权重 + KV cache，给出 🟢🟡🔴 预算判断（简化公式 `kv_per_token ≈ 0.00005 × params_b GB`）
- `gen-cmd` — 生成完整 `python -m vllm.entrypoints.openai.api_server ...` + curl 验证命令，**打印到终端让用户 review 后 paste**（不自动启动，保留人工 review 窗口）

### skills/precision-alignment/run.sh（155 行）

3 个模式：

- `gen-hook <OUT.py>` — 生成 `register_forward_hook` 注入 + 每层 tensor dump 的 Python 脚本。自动挑 "有意义层"（rotary / q_proj / k_proj / norm / mlp），支持 `--layers N` 限前 N 层防 dump 爆盘
- `gen-compare <OUT.py>` — 生成 max_diff + cosine 对比脚本，**第一发散层自动映射到对应 pitfall**（看到 "rotary" 就提示 rope-half-convention，看到 "norm" 就提示 dtype-mixing）
- `run-compare <gpu.pt> <npu.pt>` — 环境里有 torch 时直接跑；没 torch 则明确报错退出

### 共同工程决策

- **shebang `#!/usr/bin/env bash` + `set -euo pipefail`** —— 沿袭 wiki-consolidate-draft-to-stable 的约定
- **三个脚本都有 `--help`**，直接 `grep '^#' "$0" | sed 's/^# \?//'` 把头部注释当 help
- **生成 Python 模板而非直接跑** —— 把 "需要用户改参" 的地方留 TODO 注释，降低误操作
- **每个 pitfall 在脚本里有引用**（行内注释形式），让看代码的人直接跳去读坑本
