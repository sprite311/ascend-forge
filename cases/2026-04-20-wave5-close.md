# Wave 5 收尾：bench 100%、4 adapters、R033 晋升、5 工具抽公共、10 条架构反思

## 背景

Wave 1–4 把骨架搭到端到端可跑：
- Wave 1–2：5 种知识底（memory / wiki / cases / rules / skills）+ 7 个 subagent

Wave 5 的目标是把"生态闭环"做完：**golden bench 验证路由（能力层）+ 非-Claude-Code 客户端适配（跨环境层）+ 规则自晋升闭环（进化层）**，并借这次做**架构反思**，识别前几 Wave 攒下的 tech debt。

## 做了什么

### 5.1 · Bench（能力层自检）

**产出**：
- `bench/golden-questions.yaml` — 15 条覆盖昇腾全栈（硬件 / CANN / torch_npu / MindIE / vLLM-Ascend / 错误码 / 性能 …）的 golden 问题，每条带 `expected_subagent` + `expected_wiki_hits`。
- `tools/bench.py` — 纯 stdlib（含一个简易 YAML parser），按关键词加权路由到 subagent + 算 wiki 命中，输出混淆矩阵 + 逐题 diff。

**运行结果**：
- 第一次：14/15（Q12「推理服务 OOM」被路由到 deployer 而非 diagnoser，因为 `服务` 同时命中两边）
- 去掉裸 `服务` 关键词（保留 `推理服务` / `多机服务`）后：**15/15（100%）**

**但这不完全是胜利**：见架构反思 #4——15 条 golden 太少，分类器健康度没有真正被验证。后续要把题库扩到 30+ 再评估。

### 5.2 · Adapters（跨客户端层）

产出 4 份 `adapters/<client>/README.md`：
- `adapters/claude-code/` — 能力基线（100%）
- `adapters/openclaw/` — 能力 ~85%（支持 subagent + skills + 文件协议，缺 hooks）
- `adapters/cursor/` — 能力 ~70%（`.cursor/rules/*.mdc` 按 glob 映射；subagent 退化为"role prompt"）

- `adapters/README.md` — capability-tier 对比图

**现状**：只写了 README，没写**真的能跑**的同步脚本。见架构反思 #10。

### 5.3 · 规则自晋升闭环

第 1 / 2 / 3 条 evidence：
- `cases/2026-04-20-porting-selfcheck.md`（Wave 1 产出，已存在）
- `cases/2026-04-20-draft-wiki-qwen3.md`（本 Wave 新增：用户问 qwen3 910B 吞吐 → draft 页降权）
- `cases/2026-04-20-draft-wiki-flash-attention.md`（本 Wave 新增：用户问 flash-attention 算子 → draft + TBD 页降权）

跑 `tools/evolve.py` Step 7 → 🟢 `seed-critical-wiki-before-first-use` evidence=3。

**新建 `tools/promote.py`**：
- `--dry-run` 默认，打印将对 ACTIVE.md / archive / proposal 做的三件事
- `--apply` 真落盘
- section 分组（planning R0xx / knowledge R1xx / safety R2xx / evolution R3xx）自动分配下一个 ID
- **Fallback 1**：沙箱 `Path.unlink()` PermissionError → 自动改成把原 proposal frontmatter `status: pending` → `promoted` + 追 `promoted_at / promoted_to / archive_ref`
- **Fallback 2（本 Wave 修）**：section 末尾检测原本只识别 `\n##\s`，不识别 `\n---\s*\n`，导致 R033 被插到了"尾部分隔线之后"。修成同时识别两种终止符

跑 `tools/promote.py --id seed-critical-wiki-before-first-use --apply`：
- R033 入 `rules/ACTIVE.md` → **"命中 `status: draft` 或含 `TBD` 的 wiki 页时，回答必须：(1) 首行 `⚠️ 低置信度` 标注 (2) 给验证命令 (3) 不把猜测值写入 `memory/facts/`"**
- `rules/archive/promoted-2026-04-21-seed-critical-wiki-before-first-use.md` 留存完整提案副本
- 原 proposal 文件改 `status: promoted`（unlink fallback）

再跑 `tools/evolve.py` Step 7 → `✅ seed-critical-wiki-before-first-use status=promoted`，`proposals_ready = 0`（符合预期，不再计为 ready）。
